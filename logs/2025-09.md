## **Revenge of the PETSCII Robots**

* Began undoing step-based movement and re-implementing smooth movement.
  - Ex: Instances moving in tile-width or half-tile-width "steps" every so often versus moving smoothly from 1 to 3 pixels at a time many times a second.
  - Evaluating what these changes broke. These changes broke a lot.
  - Ex: Every instance is looking one tile-width ahead of them, preventing them from approaching other instances.
  - Fixed player's ability to collide with other instances caused by re-implementing smooth movement.
* Fixed long-time issue: The player character correctly moves in a new direction if there is a second dirctional input.
  - Ex: The human player presses right, and then up, while still holding right -> The player character changes from moving right to moving up.
  - Previously, movement direction conflicts would be settled by where the directions lay on the if - else chains.
* Refactoring the player character's code into states.
