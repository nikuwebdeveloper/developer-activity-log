## **Revenge of the PETSCII Robots**

### Commentary

On the last day of the month, combat finally came back together and felt like something substantial. The game had been in pieces for a long time because of massive code re-writes and it feels much more solid now. A chunk of time was wasted this month trying to rewrite or create pathfinding behavior. I solved the issue by making small changes to the provided pathfinding functions. I remembered "don't reinvent the wheel" and then I stopped, and now it's good enough. Also, I tried using Ubuntu's version of GameMaker on Kubuntu but I don't trust that version at all. I know that "enstruct" is not a real word, but I'm going to start using it.

_enstruct (v) - reorganizing code into a struct_
